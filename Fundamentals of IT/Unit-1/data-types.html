Data and Its Types

Data is the raw form of information. It is a collection of facts, figures, symbols or observations that represent details about events, objects or phenomena.

By itself, data may not provide meaningful information. When data is organized, processed and interpreted, it can be transformed into useful information and insights.

Simple idea:

Data → Processing → Meaningful Information

In data science and computing, data is categorized into different types based on its nature, structure and how it is represented.

Quantitative Data

Quantitative data is data that can be measured, counted and expressed in numerical form.

It answers questions such as:

  • How many?
  • How much?
  • How often?
  • What is the value?

Examples

  • Age = 20 years
  • Height = 170 cm
  • Weight = 65 kg
  • Number of students = 50
  • Temperature = 32°C
  • Monthly income = ₹40,000
  • Number of computers = 25

Quantitative data is mainly divided into two types:

  1. Discrete Data
  2. Continuous Data

Discrete Data

Discrete data consists of values that are countable and are usually expressed as whole numbers.

The values occur as separate and distinct units. Discrete data is obtained through counting.

Examples

  • Number of students in a class = 45
  • Number of books = 120
  • Number of cars = 8

Normally, fractions do not make sense when we are counting separate objects. For example, a classroom can have 40 or 41 students, but not 40.5 students.

Characteristics of Discrete Data

Characteristic Description
Nature Countable
Values Separate and distinct
Usually represented by Whole numbers
Decimals / Fractions Generally not meaningful
Obtained by Counting

Continuous Data

Continuous data consists of values that can take any value within a given range.

It is obtained through measurement and can include decimals and fractions.

Examples

  • Height = 172.5 cm
  • Weight = 65.75 kg
  • Temperature = 36.7°C
  • Time = 12.45 seconds
  • Distance = 5.68 km

For example, a person's height can be 170 cm, 170.1 cm, 170.15 cm, 170.156 cm and so on, depending on the precision of measurement.

Characteristics of Continuous Data

Characteristic Description
Nature Measurable
Values Any value within a range
Usually represented by Integers, decimals or fractions
Decimals / Fractions Meaningful
Obtained by Measurement

Discrete Data vs Continuous Data

Feature Discrete Data Continuous Data
Meaning Obtained by counting Obtained by measuring

Decimal values Generally not applicable Applicable

Example Number of students Height of students

Remember:

Discrete = Counting

Continuous = Measuring

Qualitative Data

Qualitative data describes qualities, characteristics or attributes rather than numerical values.

It is generally non-numerical and is used to understand opinions, behaviours, experiences and categories.

Qualitative data may be collected through interviews, focus groups, personal diaries, laboratory notes, maps, photographs and other observations or written records.

Examples

  • Colour
  • Brand
  • Gender
  • Customer feedback

Two important types of qualitative data covered in the material are Nominal Data and Ordinal Data.

Nominal Data

Nominal data is categorical data used to label or classify items into different groups without any order or ranking.

The categories are distinct and mutually exclusive. They represent names or qualities rather than numerical values.

Since there is no meaningful order between the categories, arithmetic operations cannot be meaningfully performed on nominal data.

Characteristics of Nominal Data

  • It is qualitative in nature.
  • It describes categories or labels.
  • Categories are distinct and mutually exclusive.
  • There is no fixed order or ranking.
  • Addition, subtraction, multiplication and division cannot be meaningfully performed.
  • The mode can be calculated.
  • Mean and median cannot be determined from nominal categories.

Methods of Collecting Nominal Data

  • Surveys and Questionnaires: Multiple-choice questions can be used to classify responses into categories.
  • Interviews: Direct questions can be used to collect categorical information.
  • Observation: Categories can be recorded based on visible characteristics.
  • Administrative or Official Records: Existing records and databases can provide category-based information.
  • Online Forms and Registration Sheets: Dropdown menus, radio buttons and checkboxes can collect categorical responses.

Visualisation of Nominal Data

  • Frequency tables: Show categories with their frequencies or counts.
  • Bar charts: Represent each category using a bar whose size corresponds to its frequency.
  • Pie charts: Show the proportion of each category as a part of the whole.

Ordinal Data

Ordinal data is categorical data in which the categories have a meaningful order or ranking.

However, the exact differences or intervals between the categories cannot be measured or assumed to be equal.

Examples

Customer Satisfaction:

Very Bad → Bad → Okay → Good → Excellent

Education Level:

High School → Bachelor's → Master's → PhD

Likert Scale:

Strongly Disagree → Disagree → Neutral → Agree → Strongly Agree

Characteristics of Ordinal Data

  • Categories have a meaningful ranking.
  • The exact difference between consecutive categories is not known.
  • The intervals between categories may not be equal.
  • It is commonly used for opinions, preferences, satisfaction levels and grades.
  • Arithmetic operations such as addition, subtraction, multiplication and division cannot be meaningfully performed on the categories.
  • Because the data is ordered, rankings, median and percentiles can be determined.
  • It is commonly collected through rating scales, questionnaires and feedback forms.

Structured Data

Structured data is data organized in a predefined format. It follows a well-defined structure or data model.

It is commonly stored in rows and columns, which makes it easier for both humans and computers to read, retrieve and analyse.

Example

A customer database can contain fields such as:

  • Name
  • Address
  • Phone Number
  • Email

Characteristics of Structured Data

  • Follows a predefined structure.
  • Stored in rows and columns.
  • Data has clearly defined meaning and format.
  • Data resides in fixed fields within records.
  • Data elements can be efficiently accessed and processed.

Common Sources

  • Relational databases
  • Spreadsheets
  • Online forms and surveys
  • Web and server logs
  • IoT sensors
  • Medical monitoring devices

Relational Database

A relational database organizes data into tables.

These tables contain rows and columns. Each row represents a record, while columns represent particular fields or attributes.

Relational databases are useful because organized data can be stored and retrieved efficiently.

Queries can be used to search for and retrieve specific information from the organized data. SQL is commonly used for working with relational databases.

Simple example:

A student table may contain:

Roll No. | Name | Course | Marks

Each row represents one student's record.

Unstructured Data

Unstructured data is information that does not have a predefined format or fixed structure.

In simple words, it is data that is messy, unorganized and does not fit neatly into rows and columns like a spreadsheet.

Because it does not follow a clear pattern, unstructured data can be more difficult to store, process and search.

Examples

  • Photos
  • Videos
  • Audio files
  • Emails
  • Social media posts
  • Comments
  • Reports and articles
  • PDFs and Word files
  • Websites and blogs

Characteristics of Unstructured Data

  • It has no fixed predefined structure.
  • It can contain text, images, audio and video.
  • It can come from many different sources.
  • It can be very large in volume.
  • It is more difficult to categorize and organize.

Challenges with Unstructured Data

  • Hard to store: Different formats may require large and varied storage systems.
  • Difficult to search: Without labels or organization, finding specific information can be difficult.
  • Difficult to analyse: Special software and more complex techniques may be required.

Extracting Information from Unstructured Data

Since unstructured data does not have a fixed structure, techniques can be used to organize and extract useful information from it.

1. Tagging

Tagging means adding labels or keywords to data so that it can be identified and found more easily.

For example, a photograph of a dog could be tagged with words such as "dog", "pet" or "animal".

2. Classifying Data

Classification means organizing data into groups or categories.

For example, customer reviews can be grouped into positive and negative feedback.

3. Data Mining

Data mining helps find patterns and useful information in large amounts of data.

For example, customer reviews can be analysed to find common complaints or social media posts can be studied to identify patterns and trends.

Structured Data vs Unstructured Data

Feature Structured Data Unstructured Data
Format Organized in rows and columns No fixed format
Examples Names, ages and addresses in a database Photos, videos, emails and social media posts
Storage Relational databases such as SQL Files, cloud storage or NoSQL databases
Analysis Easier to search, sort and analyse Requires advanced processing
Data form Predictable text and numbers Mixed text, audio, video and images

Semi-Structured Data

Semi-structured data does not reside in a traditional relational database like SQL, but it still has some organizational properties.

It does not follow a strict schema like structured data, but it contains elements such as tags, markers, labels or keys that make the data identifiable and searchable.

Characteristics of Semi-Structured Data

1. Flexible Schema

The structure can vary from one entry to another. For example, one JSON object may contain five fields while another may contain only three.

2. Human-Readable Format

Formats such as JSON and XML can be understood by both humans and machines.

3. Scalable

Semi-structured data can be handled by modern NoSQL databases and is useful in Big Data environments.

4. Metadata-Rich

Tags and attributes provide additional context, which helps in sorting and analysing the data.

Examples of Semi-Structured Data

  • JSON
  • XML
  • CSV files with inconsistent rows
  • Emails with structured headers and unstructured body text
  • Sensor data from IoT devices
  • HTML web pages

JSON

JSON stands for JavaScript Object Notation.

It is an example of semi-structured data. JSON uses keys and values to organize information without requiring every record to follow exactly the same structure. 


{
    "name": "Shuaib",
    "course": "Data Science",
    "semester": 1
}

Here, the labels such as name, course and semester help identify the stored values.

Metadata

Metadata means information that provides additional information or context about other data.

In semi-structured data, tags and attributes can provide metadata that helps identify, organize, sort and analyse the data.

Simple idea:

Data = the actual information

Metadata = information that describes or gives context about that data

Challenges of Semi-Structured Data

  • Complex Querying: Queries may not be as straightforward as SQL queries on structured data.
  • Data Cleaning: Irregular structures can cause inconsistency and make integration more difficult.
  • Tool Compatibility: Not every analytics tool supports all semi-structured formats directly.

Structured, Semi-Structured and Unstructured Data

Feature Structured Semi-Structured Unstructured
Structure Fixed Flexible No predefined structure
Common form Rows and columns Tags, keys and markers Free-form data
Examples SQL tables, spreadsheets JSON, XML, HTML Photos, videos, audio
Searching / analysis Easier Moderate / more complex More difficult

CRUD

CRUD represents four basic operations that can be performed on data:

  • C — Create: Add new data.
  • R — Read: View or retrieve existing data.
  • U — Update: Modify existing data.
  • D — Delete: Remove data.

Create → Read → Update → Delete

Key Points to Remember

  • Data is the raw form of information.
  • Quantitative data is numerical and can be measured or counted.
  • Discrete data is obtained by counting.
  • Continuous data is obtained by measurement and can contain decimals or fractions.
  • Qualitative data describes qualities, characteristics or categories.
  • Nominal data has categories without ranking.
  • Ordinal data has categories with meaningful ranking.
  • Structured data follows a predefined format.
  • Unstructured data has no predefined format.
  • Semi-structured data has some organization through tags, keys or markers but does not follow a strict schema.
  • JSON is an example of semi-structured data.
  • Metadata provides additional information or context about data.
  • CRUD stands for Create, Read, Update and Delete.
