Character Representation

Computers need to represent characters such as letters, numbers, symbols and special characters in a form that they can store and process.

Since computers work internally with binary data, characters are represented using numerical codes.

Basic Idea:

A character is assigned a numerical code, and the computer uses that code to represent and process the character.

ASCII

ASCII stands for American Standard Code for Information Interchange.

ASCII is a character encoding system used to represent characters in computers.

It provides numerical codes for characters such as letters, digits and commonly used symbols.

Basic ASCII

Standard ASCII uses 7 bits to represent a character.

With 7 bits, a total of 128 different codes can be represented.

These codes are used for characters such as:

  • Uppercase letters
  • Lowercase letters
  • Digits
  • Punctuation marks
  • Control characters

Example

The character A has an ASCII numerical code.

The important idea is that the computer does not store the letter as a physical letter. It stores its corresponding code.

Extended ASCII

Extended ASCII uses 8 bits and provides more possible character codes than standard 7-bit ASCII.

With 8 bits, up to 256 different values can be represented.

The additional codes can be used for extra characters and symbols.

Remember:

ASCII → 7 bits → 128 codes

Extended ASCII → 8 bits → 256 possible values

Unicode

Unicode is a character encoding standard designed to represent a very large range of characters from different writing systems.

Unlike basic ASCII, Unicode is not limited to only common English characters.

It can represent characters from many different languages and writing systems.

This makes Unicode suitable for modern computer systems where information may need to be written in different languages.

Examples of Characters Represented by Unicode

  • English characters
  • Arabic characters
  • Hindi characters
  • Chinese characters
  • Mathematical symbols
  • Many other symbols and writing systems

Why is Unicode Important?

ASCII mainly focuses on a limited set of commonly used characters, while computers today need to handle text from many languages.

Unicode provides a common way to represent a very large collection of characters.

Therefore, Unicode helps computers store, process and display multilingual text.

ASCII vs Extended ASCII vs Unicode

Feature ASCII Extended ASCII Unicode
Bits 7 bits 8 bits Uses different encoding forms
Number of codes 128 256 possible values Very large range of characters
Main purpose Common characters More characters and symbols Characters from many languages

Simple Example

Suppose you type the word:

CAT

The computer does not simply store the letters C, A and T in the same way humans see them.

Each character is represented using its corresponding character code, which can then be represented internally using binary data.

Character → Character Code → Binary Representation

Quick Revision

  • Character representation allows computers to store and process characters.
  • ASCII stands for American Standard Code for Information Interchange.
  • Standard ASCII uses 7 bits and provides 128 codes.
  • Extended ASCII uses 8 bits and provides up to 256 possible values.
  • Unicode provides a way to represent a very large range of characters from different languages.
  • Character codes can ultimately be represented internally using binary data.
