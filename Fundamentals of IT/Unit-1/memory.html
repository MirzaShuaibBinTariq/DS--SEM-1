Memory

Computer memory is the part of a computer that is used to store data, instructions and information.

The computer uses memory to keep the data and instructions that are needed while performing different tasks.

Basic Idea:

Memory is the storage area of a computer where data and instructions are kept.

Types of Memory

Computer memory can be broadly divided into two main types:

  1. Primary Memory
  2. Secondary Memory

Primary Memory

Primary memory is the memory that is directly used by the computer while processing data and instructions.

It is also called the main memory of the computer.

The two important types of primary memory are:

  • RAM
  • ROM

RAM — Random Access Memory

RAM stands for Random Access Memory.

RAM is used to temporarily store data and instructions that the computer is currently using.

RAM is volatile memory. This means that the stored data is lost when the computer is switched off.

Remember:

RAM stores data temporarily using electrical signals. When the power or electrical signal is lost, RAM loses its stored data.

ROM — Read Only Memory

ROM stands for Read Only Memory.

ROM is used to store information and instructions that need to remain stored even when the computer is switched off.

ROM is non-volatile memory. Therefore, its stored information is not lost when the power is turned off.

Secondary Memory

Secondary memory is used for storing data and files for a longer period of time.

It is non-volatile, which means that the stored data remains available even after the computer is switched off.

Examples of secondary storage include:

  • Hard Disk Drive (HDD)
  • Solid State Drive (SSD)
  • CD
  • DVD

RAM vs ROM

RAM ROM
Random Access Memory Read Only Memory
Volatile memory Non-volatile memory
Data is lost when power is switched off Data remains stored after power is switched off
Used for temporary storage Used for storing information that needs to be retained

Quick Revision

  • Memory stores data and instructions.
  • There are two main types: Primary Memory and Secondary Memory.
  • Primary memory includes RAM and ROM.
  • RAM is temporary and volatile.
  • ROM is non-volatile.
  • Secondary memory is used for long-term storage.
