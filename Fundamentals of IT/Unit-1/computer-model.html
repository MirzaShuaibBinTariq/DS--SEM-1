Simple Model of a Computer

A computer works by accepting data and instructions, processing them and producing a useful result.

The basic working of a computer can therefore be understood through a simple sequence:

Input   →   Processing   →   Output

Algorithm

An algorithm is a step-by-step procedure used to solve a problem or perform a task.

Before a computer performs a task, the steps required to solve the problem can be planned as an algorithm.

Simple Example

Suppose we want to calculate the total of two numbers.

  1. Start.
  2. Take the first number.
  3. Take the second number.
  4. Add the two numbers.
  5. Display the result.
  6. Stop.

Remember:

Algorithm = Step-by-step method for solving a problem.

Input

Input is the data or instructions given to a computer so that it can perform a task.

Input can be provided by the user through different input devices.

Examples of Input

  • Typing text using a keyboard
  • Clicking using a mouse
  • Touching a touch screen
  • Scanning a document

Input devices convert the user's actions or data into signals that the computer can process.

Processing

After receiving the input, the computer processes the data according to the given instructions.

The main component responsible for processing is the Central Processing Unit (CPU).

The CPU performs calculations, makes decisions and controls the operations required to process the input.

Central Processing Unit (CPU)

The CPU is the main processing unit of a computer. It processes instructions and data and controls the operations of the computer.

The main parts of the CPU are:

  1. Arithmetic Logic Unit (ALU)
  2. Control Unit (CU)
  3. Registers

Arithmetic Logic Unit (ALU)

The ALU performs arithmetic and logical operations.

Arithmetic operations include calculations such as addition and subtraction.

Logical operations are used when the computer needs to compare or make logical decisions.

Control Unit (CU)

The Control Unit controls and coordinates the activities of the computer.

It directs the different parts of the computer so that instructions are carried out in the correct order.

Registers

Registers are small, fast storage locations used by the CPU while processing data and instructions.

They hold information that the CPU needs during processing.

Output

Output is the result produced after the computer has processed the input.

The result can be presented to the user using different output devices.

Examples of Output

  • Text displayed on a monitor
  • A printed document
  • Sound produced through speakers

Data Processing Using a Computer

Data processing is the process of converting input data into useful information through computer processing.

The basic process can be understood in three main stages:

1. Input

Raw data and instructions are entered into the computer.

2. Processing

The CPU processes the input according to the given instructions.

3. Output

The processed result is provided to the user as useful information.

Input → Processing → Output

Example of Computer Processing

Suppose a student enters two numbers into a computer and wants to find their sum.

Input

The student enters the two numbers using a keyboard.

Processing

The CPU receives the numbers and performs the addition operation.

Output

The answer is displayed on the computer screen.

Example:

Input: 10 and 20

Processing: 10 + 20

Output: 30

Key Points to Remember

  • An algorithm is a step-by-step procedure for solving a problem.
  • Input is the data or instructions given to a computer.
  • The CPU performs the main processing.
  • The ALU performs arithmetic and logical operations.
  • The Control Unit coordinates computer operations.
  • Registers provide small and fast storage for the CPU during processing.
  • Output is the result produced after processing.
  • The basic computer process is: Input → Processing → Output.
