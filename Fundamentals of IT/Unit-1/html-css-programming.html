HTML, CSS & Programming

HTML and CSS are important technologies used for creating and designing web pages.

HTML

HTML stands for HyperText Markup Language.

HTML is used to create the structure and content of a web page.

It tells the web browser what elements should appear on a page, such as headings, paragraphs, links, images and forms.

Simple idea:

HTML = Structure of a web page

Main Purpose of HTML

The main purpose of HTML is to define the structure and content of a web page.

HTML uses elements and tags to describe different parts of a webpage.

Common HTML Elements

  • Headings
  • Paragraphs
  • Links
  • Images
  • Lists
  • Forms

HTML Form

An HTML form is used to collect information or input from a user.

For example, a form can be used to collect:

  • Name
  • Email address
  • Password
  • Other information entered by the user

Example:

A login page can use an HTML form to collect a username and password.

Simple HTML Example 

<h1>PENCIL BEATS</h1>

<p>Welcome to my website.</p>

The <h1> element creates a heading, while <p> creates a paragraph.

CSS

CSS stands for Cascading Style Sheets.

CSS is used to control the appearance and design of a web page.

It can be used to change things such as colours, fonts, spacing, borders, sizes and the layout of elements.

Simple idea:

CSS = Design and appearance of a web page

Main Purpose of CSS

The main purpose of CSS is to style HTML elements and control how they appear on the screen.

For example, CSS can control:

  • Text colour
  • Font size
  • Background colour
  • Spacing
  • Borders
  • Page layout

HTML and CSS Together

HTML and CSS perform different roles but work together when creating a web page.

HTML → Structure
CSS → Style

For example, HTML can create a heading, while CSS can change the heading's colour, size and position.

Java

Java is a programming language used to develop different types of software and applications.

C++

C++ is a general-purpose programming language used to develop software and applications.

HTML vs CSS

Feature HTML CSS
Full form HyperText Markup Language Cascading Style Sheets
Main role Creates structure and content Controls appearance and design
Examples Headings, paragraphs, links, forms Colours, fonts, spacing, layout
