Floating-Point Representation

Floating-point representation is a method used by computers to represent numbers that may contain a fractional or decimal part.

Examples of such numbers are:

3.14    25.5    0.125

Floating-point representation allows computers to represent both very large and very small numbers.

Basic Idea

A floating-point number is represented using different parts that describe the number.

The important parts are:

  • Sign — indicates whether the number is positive or negative.
  • Exponent — indicates the position or scale of the number.
  • Significand — contains the significant digits of the number.

Sign + Exponent + Significand

Single Precision

Single precision is a floating-point format that uses 32 bits to represent a number.

The 32 bits are divided into three parts:

  • 1 bit for the sign
  • 8 bits for the exponent
  • 23 bits for the fraction (significand)

Single Precision = 32 bits

1 bit Sign   +   8 bits Exponent   +   23 bits Fraction

Single precision uses less memory than double precision and provides a smaller level of numerical precision.

Double Precision

Double precision is a floating-point format that uses 64 bits to represent a number.

The 64 bits are divided into:

  • 1 bit for the sign
  • 11 bits for the exponent
  • 52 bits for the fraction (significand)

Double Precision = 64 bits

1 bit Sign   +   11 bits Exponent   +   52 bits Fraction

Double precision provides greater precision and a larger range of values than single precision, but it requires more memory.

Why is Floating-Point Representation Used?

Many real-world values contain fractional parts and cannot be represented conveniently using only integers.

Floating-point representation allows a computer to work with numbers such as:

  • 3.14159
  • 12.75
  • 0.00125

It is useful when calculations require numbers with decimal or fractional values.

Single Precision vs Double Precision

Feature Single Precision Double Precision
Total size 32 bits 64 bits
Sign bits 1 1
Exponent bits 8 11
Fraction bits 23 52
Precision Lower Higher
Memory required Less More

Quick Revision

  • Floating-point representation is used for numbers that can contain fractional values.
  • A floating-point representation contains a sign, exponent and significand/fraction.
  • Single precision uses 32 bits.
  • Single precision has 1 sign bit, 8 exponent bits and 23 fraction bits.
  • Double precision uses 64 bits.
  • Double precision has 1 sign bit, 11 exponent bits and 52 fraction bits.
  • Double precision provides greater precision but requires more memory.
